# Notesyyy Project
Notesyyy is a godot plugin project that i made for godot users its idea comes from my mind.


## Features 
notesyyy helps you will you are making your game as that instead of begining without plan or write a one on another app you can write notes and make a plan for your game and when you finish each plan just delte its note without many talk it is a notes app in godot 


### How to use
All you need to use it is to download notesyyy folder from the addons folder and then extract the files after extracting put this folder in your project addon's folder and then from project choose project setting and then plugins and then click on enable button then it will start working and just start writing your notes.



#### How is it usefull 
I think the most important part in it that if you are working on a project and you want to complete working on it next day so in the next day i am sure that you will take about half hour asking yourself about from where will you start today but with notesyyy all you need to do is to write a plan about what you will do in the next day and in the next day you can read your notes and remember from where to start.

##### Small note 
This is the first version of the plugin so it have a small problem in saving the notes so please when you add a new note please make sure to press ( ctrl + s ) to make sure that it is saved and the same thing for deleting a note.
